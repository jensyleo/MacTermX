# Security Policy

## Supported Versions

MacTermX is under active development, pre-1.0. Only the latest commit on
`main` is supported — there are no maintained older release branches yet.

## Reporting a Vulnerability

If you find a security vulnerability in MacTermX, please report it
privately via [GitHub Security Advisories](https://github.com/jensyleo/MacTermX/security/advisories/new)
rather than opening a public issue.

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce it.
- Any relevant logs, session captures, or transferred-file samples needed
  to reproduce it (redact anything sensitive first — never include real
  device credentials or production console output).

You should expect an initial response within a few days. There is no
bug bounty program for this project.
