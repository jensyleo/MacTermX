# Code of Conduct

MacTermX is a small personal project. The expectation for anyone
participating — issues, pull requests, discussions — is simple:

- Be respectful and assume good faith.
- Keep disagreements about code, design, or scope; not about people.
- No harassment, personal attacks, or discriminatory language.

Reports of a violation, or questions about this, can go to the maintainer
directly via a GitHub issue or a private message to the repository owner.
There's no formal enforcement committee — for a project this size, the
maintainer handles it directly, up to and including blocking repeat
offenders from the repository.
